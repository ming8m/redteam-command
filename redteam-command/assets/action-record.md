# 单次工具动作附件

保存在当前案件或任务的产出目录并关联任务记录。这是证据附件，不是运行状态源；缺项标未知，不保存明文秘密。

- 案件标识 / Task ID / Owner / 实际执行者：
- 实验 ID / 假设 ID / context_id / 对应正常基线：
- action_id（逻辑动作）/ attempt_id（本次尝试，重试另建）：
- 工具或 API / 版本 / 实际 argv 列表或结构化输入受控引用：
- 目标、测试身份/对象别名、允许操作及范围依据：
- 固定条件 / 唯一改变的维度 / 预期观察 / 阴性对照 / 证伪条件：
- 起止时间及时区 / 返回码 / 超时或中断 / 请求及成本消耗：
- stdout、stderr、对象效果或授权方遥测附件 / 稳定定位 / SHA-256：
- 原始或派生 / 完整或截断 / 脱敏范围及语义影响：
- 实际观察 / 工具执行事实 / 目标端效果 / 未知（分别说明）：
- 新增信息 / 竞争解释 / 同一失败分支及已有无新增信息次数：
- 副作用 / 前后对象状态 / 恢复动作与证据 / 遗留与负责人：
- 下一项最小判别动作 / 必要新前提 / 需要等待的其他任务：

工具返回不等于漏洞确认。无法观察目标端状态时不能填写“已回滚”或“没有副作用”；通过调用方实际支持的方式保存未知与限制。
